Caso de Estudio: Portfolio Web Personal


El Problema

Necesitaba diseñar y desarrollar un portfolio web para presentar mi perfil profesional que fuera 100% accesible, responsive y que se alejara de las plantillas genéricas oscuras, reflejando una identidad más limpia y técnica.


El Proceso UX/UI

El diseño comenzó definiendo a mi usuario objetivo: un reclutador IT con poco tiempo. Realicé un benchmark de tres portfolios referentes y armé un moodboard con tres palabras clave: Técnico, Moderno, Confiable. Elegí una paleta "Azul Naval" para transmitir profesionalismo y armé wireframes y prototipos navegables en Figma para probar la usabilidad antes de codear.


El Desarrollo y Resultado

El sitio fue maquetado utilizando HTML semántico y una arquitectura CSS puro (Mobile-first, Flexbox y Grid). Se optimizaron las imágenes y el contraste de colores para cumplir con las normativas WCAG 2.2 nivel AA. El resultado final logró superar los 90 puntos en las 4 métricas de Lighthouse (Performance, Accesibilidad, Mejores Prácticas y SEO).
